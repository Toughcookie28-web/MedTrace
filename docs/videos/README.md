## How to Record:

1. **Tools:**
   - OBS Studio (free, desktop recording)
   - Loom (browser-based, easy)
   - QuickTime (Mac screen recording)

2. **Tips:**
   - **1080p resolution** minimum
   - **Clear audio** (use external mic if possible)
   - **Follow DEMO.md script**
   - **Show browser console** for technical audience
   - **No personal information** visible

3. **Editing:**
   - Add intro/outro slides
   - Speed up slow parts (2x speed)
   - Add captions/subtitles
   - Background music (royalty-free)
